# Clase 0 — Entrada en Calor (HTML + CSS + Primer Pull Request)

## Objetivo
Perder el miedo a VS Code, practicar el flujo de **Fork + Pull Request**, incorporar nociones básicas de **HTML semántico** y **Box Model** (`margin`, `border`, `padding`), y armar tu primera página web simple mientras preparamos la Clase 1 de TypeScript.

## Consigna
Creá dentro de `entregas/<tu-usuario-github>/clase-00/` dos archivos: `index.html` y `styles.css`.

Armá una **tarjeta de presentación** (puede ser tuya o de un negocio ficticio de Bovril: peluquería, gimnasio, despensa o rotisería) que incluya:
1. Un título principal (`<h1>`) y un subtítulo o descripción (`<p>`).
2. Una imagen (`<img>`).
3. Una lista de al menos 3 servicios, productos o gustos (`<ul>` y `<li>`).
4. Un enlace o botón (`<a>` o `<button>`).
5. En `styles.css`: colores, tipografía, bordes redondeados, sombra suave y la tarjeta centrada en pantalla.

## Cómo entregarla
Seguí los 5 pasos de [`docs/flujo-entregas.md`](../../docs/flujo-entregas.md) y abrí tu primer Pull Request antes de la Clase 1.
