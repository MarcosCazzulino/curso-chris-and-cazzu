El Mapa · 12 Semanas

¿Qué vas a construir?

No vamos a hacer ejercicios sueltos sin destino: todo converge en un producto web real y vendible publicado en tu propia cuenta.

Fase 1 · Semanas 1–4

Lógica pura en TypeScript, JSON, DOM, HTTP, APIs REST y Examen 1 + definición de MVP.

Fase 2 · Semanas 5–8

React + Vite + Tailwind, Arquitectura de BD, SQL puro en Supabase, TanStack Query y Examen 2.

Fase 3 · Semanas 9–12

Auth, Roles, RLS, Zustand, Backend propio en Express + JWT, Deploy, DNS y Defensa Final.

Reglas de Juego

Cómo se cursa y se aprueba

  • Ritmo semanal: 6 a 8 hs de práctica tuya (lun–jue, entrega antes del jueves 23:59) + 2 a 4 hs en vivo el finde.
  • 3 Exámenes eliminatorios (nota mínima 7): 40 % Pseudocódigo tipado en vivo (sin IA, estricto en tipos y lógica) + 30 % Oral + 30 % Entregable.
  • Honestidad con la IA: podés usar IA en la semana para destrabarte, declarándolo en el PR. Si en clase no sabés explicar una función que subiste, vale 0.
  • Dudas entre semana: primero al grupo; si nadie la saca, arrobás al profe enviando qué probaste, el código y el error exacto.

Fundamentos Web

Cómo funciona una página web

El navegador (Chrome/Brave) lee tres capas bien separadas para dibujar y dar vida a una pantalla:

1. HTML

Estructura y significado. Qué elementos existen: títulos, párrafos, listas, imágenes y botones.

2. CSS

Presentación visual. Colores, tipografía, espaciados, bordes y adaptación a celular/PC.

3. JavaScript / TS

Comportamiento y datos. Qué pasa al hacer clic, validaciones y comunicación con el servidor.

Buenas Prácticas desde el Día 0

HTML Semántico

Evitá usar <div> para todo: cada etiqueta comunica qué rol cumple (ayuda a la accesibilidad y al orden del código). 

<main class="tarjeta">
  <header>
    <h1>Barbería Don Pepe</h1>
    <p>Turnos por orden de llegada y reservas online.</p>
  </header>

  <ul>
    <li>Corte clásico</li>
    <li>Perfilado de barba</li>
    <li>Corte + barba</li>
  </ul>

  <a href="#contacto" class="boton">Reservar turno</a>
</main>

CSS Esencial

El Box Model (Modelo de Caja)

Todo elemento en pantalla es una caja compuesta por 4 capas. Dominar esto evita el 90 % de las peleas con CSS:

Margin — espacio exterior que separa de otras cajas
Border — el contorno visible de la caja
Padding — aire interior entre el borde y el texto
Content — tu texto, imagen o botón

Práctica · Entregable 0

Consigna de la Clase 0

Creá entregas/<tu-usuario-github>/clase-00/index.html y styles.css con una tarjeta de presentación (tuya o de un comercio local):

  • 1. Un título principal (<h1>) y una descripción corta (<p>).
  • 2. Una imagen (<img>) con atributo alt descriptivo.
  • 3. Una lista de al menos 3 servicios, productos o gustos (<ul> y <li>).
  • 4. Un enlace o botón (<a> o <button>).
  • 5. En styles.css: colores sobrios, bordes redondeados, buen padding y tarjeta centrada en pantalla.
