# Guía de Instalación (Pre-trabajo antes de la Clase 1)

## 1. Programas Obligatorios
- **Visual Studio Code:** https://code.visualstudio.com/
- **Node.js (versión LTS):** https://nodejs.org/ *(descargar la versión **LTS**, que ya ejecuta `.ts` nativamente)*
- **Git:** https://git-scm.com/downloads *(en Windows, siguiente a todo)*
- **Navegador (Chrome o Brave):** https://www.google.com/chrome/

### Verificación en la terminal de VS Code (`Ctrl + ñ` o `` Ctrl + ` ``)
```bash
node -v
npm -v
git --version
```

Configurar tu identidad de Git una sola vez:
```bash
git config --global user.name "Tu Nombre"
git config --global user.email "tu-email-de-github@ejemplo.com"
```
